Ayuda

¿Qué es una solicitud POST?

POST permite enviar información desde un formulario hacia el servidor.

¿Qué es una solicitud GET?

GET se utiliza para solicitar y mostrar información de una página o recurso.

¿Para qué sirve redirect()?

redirect() permite enviar al navegador hacia otra ruta después de procesar una solicitud.

¿Por qué request.form no está disponible después de la redirección?

Porque los datos de request.form pertenecen a la solicitud POST original. Después de redirect() se realiza una nueva solicitud GET.
