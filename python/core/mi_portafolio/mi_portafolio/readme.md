# Portafolio de Juan Donoso

Portafolio personal de desarrollo web.

## Tecnologías
HTML, CSS, JavaScript, Python, Flask, MySQL, Git y GitHub.

## Cómo verlo
Abre `index.html` en el navegador. Conserva la estructura de carpetas `css/style.css` y `js/main.js`.
Tailwind CSS y Font Awesome se cargan mediante CDN, por lo que algunas partes requieren conexión a internet.

## Antes de entregar
- Añade capturas reales de tus proyectos.
- Sustituye los enlaces generales de GitHub por los repositorios individuales cuando los tengas.
- La pauta pide un video. Se quitó la sección de video por solicitud, pero será necesario incorporar una demostración de un proyecto para cumplir ese requisito.
- Publica el portafolio en un repositorio exclusivo y activa GitHub Pages.
